# 네이밍 컨벤션

> 상태: **초안**. `추정`은 2025-01-01 데이터에서 역산한 값이므로 팀 확인이 필요합니다. `【확인 필요】`는 사람이 정해야 하는 항목입니다.
> 소재·캠페인 이름을 파싱해 분석 축(타입, A/B, 주제, 시즌)을 만들기 때문에, 이 문서가 틀리면 분석 축이 전부 틀어집니다.

## 1. 캠페인명 `{매체코드}_CMP_{번호}_{목적}`
예: `GGL_CMP_01_플러스가입`

| 토큰 | 규칙 | 허용값 |
|---|---|---|
| 매체코드 | 대문자 | `GGL`=구글, `META`=메타, `NVR`=네이버 (추정) |
| `CMP` | 고정 문자열 | - |
| 번호 | 매체 내 2자리 일련번호 | `01`, `02`, `03` ... |
| 목적 | 한글 | 플러스가입, 리타겟팅, 첫구매, 신규유저, 룩얼라이크, 재구매, 브랜드KW, 일반KW (추정) |

- 캠페인명의 목적 토큰은 `캠페인목적` 컬럼과 같아야 합니다. 다르면 품질 경고 대상입니다.
- 【확인 필요】 신규 목적 값을 추가할 때의 승인 절차와, 목적별 분류 상위 그룹(신규 확보 / 리타겟팅 / 재구매 등)

## 2. 그룹명 (타겟 유형)
| 값 | 의미 (추정) |
|---|---|
| 논타겟 | 오디언스 지정 없음(광범위) |
| 유사타겟 | 유사 오디언스(룩얼라이크) |
| 리마케팅 | 방문·행동 이력 사용자 재타겟팅 |
| VIP | 우수 고객 |
| 윈백 | 이탈 고객 복귀 |

【확인 필요】 각 값의 정확한 정의와 신규 값 추가 규칙

## 3. 소재명
두 가지 형태가 있습니다. **토큰 개수로 A/B 유무를 판별합니다.**

| 형태 | 토큰 수 | 패턴 | 예 |
|---|---|---|---|
| A/B 소재 | 5 | `{타입}_{주제}_{시즌}_{A/B}_{버전}` | `VID_플러스멤버십_겨울_A_v1` |
| 단일 소재 | 4 | `{타입}_{주제}_{시즌}_{버전}` | `CRS_특가_겨울_v1` |

| 토큰 | 허용값 (추정) |
|---|---|
| 타입 | `VID`=영상, `IMG`=이미지, `CRS`=캐러셀 (확인됨), `TXT`=텍스트(검색광고) |
| 주제 | 플러스멤버십, 적립혜택, 할인쿠폰, 특가, 신상품, 배송혜택 |
| 시즌 | 겨울 (현재 값은 이것뿐) |
| A/B | `A`, `B` |
| 버전 | `v1`, `v2` ... 소재를 수정해 재제작하면 올림 |

현재 데이터에서 확인된 사실:
- `CRS`(캐러셀)는 전부 A/B 없는 4토큰 형태입니다. 【확인 필요】 캐러셀은 A/B 테스트를 하지 않는 것이 규칙인가요? (규칙이라면 `CRS`의 5토큰 형태는 오류로 처리)
- `IMG_적립혜택_겨울_v2`는 A/B 없이 `v2`입니다. 버전만 올라간 단일 소재로 해석합니다.
- **같은 소재명이 여러 매체에서 재사용됩니다** (8개). 예: `VID_적립혜택_겨울_B_v1`은 메타와 네이버에 모두 있습니다. 소재명은 단독으로 유일하지 않으므로 **분석 단위는 항상 `채널 + 캠페인 + 그룹 + 소재`** 입니다. 소재명만으로 합산하면 매체가 섞입니다.
  - 소재 자체(크리에이티브)의 성과를 보고 싶을 때는 소재명 기준으로 합산하되, 어떤 매체들이 섞였는지 함께 표기합니다.

## 4. 파싱 규칙 (구현 시)
- 구분자는 `_`. 토큰 수가 4 또는 5가 아니면 **파싱 실패**로 처리하고 값을 추측해서 채우지 않습니다. `미분류`로 두고 품질 경고에 올립니다.
- 타입 / 시즌 / A/B 값이 이 문서의 허용값에 없으면 마찬가지로 경고합니다.
- 이름 파싱 결과 컬럼: `소재타입`, `소재주제`, `시즌`, `AB`(A/B/없음), `버전`.

## 5. 예외와 변경
- 규칙에 안 맞는 이름이 들어오면: 【확인 필요】 (수정 요청 / 매핑 테이블에 수동 등록 중 선택)
- 이 문서를 바꾸면 파서와 테스트를 같이 바꿉니다.
