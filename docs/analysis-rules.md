# 분석·인사이트 규칙

> 상태: 최소 표본, 비교 기준은 확정. 나머지 `【확인 필요】`는 팀이 정할 항목입니다.
> 확정 기준은 하루치 데이터로 정했으므로, 며칠 쌓인 뒤 기간 합산 기준으로 다시 점검합니다.

## 1. 최소 표본 (이 기준 미만은 순위·결론에서 제외)
| 비교 대상 | 최소 기준 (제안) |
|---|---|
| 소재 / 그룹 ROAS·CPA 순위 | 클릭 ≥ **300** 그리고 구매 ≥ **20** (확정). 구매는 순위 기준 수치(AF 기준이면 AF 구매)로 셉니다 |
| 일별 변화 해석 | 전일·전주 동요일 모두 구매 ≥ 【확인 필요】 |
| 미달 시 | 표에는 표시하되 `표본 부족`으로 표기하고 "최고/최저" 결론에 쓰지 않습니다. |

## 2. 비교 기준
- 일별 변화: **전주 동요일 우선** (확정, 요일 효과 제거). 전일 대비는 보조로 병기합니다.
- 이상치 기준: 【확인 필요】 (예: 전주 동요일 대비 ±30% 이상)
- 기간이 다르면 비교하지 않습니다. 비교 구간을 항상 명시합니다.

## 3. A/B 테스트 판정
- 같은 `{타입}_{주제}_{시즌}`에서 `A`와 `B`만 비교합니다 (버전이 다르면 다른 소재).
- 같은 캠페인·그룹에서, 같은 기간에 집행된 경우만 유효합니다.
- 판정 기준: 【확인 필요】 (최소 집행 기간, 노출 균등성, 유의성 검정 사용 여부)
- 기준 미달이면 "승자 없음/데이터 부족"이라고 말합니다. 우세해 보여도 승자라고 단정하지 않습니다.

## 4. 비교할 때 주의
- 브랜드 검색(`브랜드KW`)은 ROAS가 구조적으로 매우 높습니다. 다른 캠페인과 같은 선상에서 순위를 매기거나, 이 수치를 근거로 예산 이동을 제안하지 않습니다.
- 매체별 운영 목적이 다릅니다 (신규 확보 / 리타겟팅 / 재구매). 같은 목적끼리 비교합니다.
- 비용이 매우 작은 행의 ROAS는 변동이 큽니다. 비용 가중(합계 기준)으로 봅니다.

## 5. 인사이트 작성 규칙
1. **사실과 가설을 구분합니다.** "ROAS가 하락했다"는 사실, "소재 피로도 때문이다"는 가설입니다. 가설에는 근거와 확인 방법을 붙입니다.
2. 모든 수치에 **기준(채널/AF), 기간, 표본 크기**를 붙입니다.
3. 변경 이력(`docs/business-context.md`)과 대조하기 전에는 원인을 단정하지 않습니다.
4. 제안은 행동 단위로 씁니다. (예: "메타 룩얼라이크 `CRS_특가_겨울_v1` 예산 축소 검토 — 근거: ..., 확인: ...")
5. 모르거나 데이터가 부족하면 그렇게 씁니다. 그럴듯한 설명을 만들어내지 않습니다.
