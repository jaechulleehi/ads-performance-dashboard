# 데이터 사전

> 상태: **초안**. 현재 데이터(2025-01-01, 38행)로 확인된 내용 위주입니다.

## 1. 입력 파일
| 항목 | 규칙 |
|---|---|
| 위치 | 프로젝트 루트 (대시보드 사이드바에서 변경 가능) 【확인 필요: 전용 `inbox/` 폴더로 분리할지】 |
| 파일명 | `YYYY-MM-DD_channel.csv`, `YYYY-MM-DD_appsflyer.csv` (날짜별 한 쌍) |
| 인코딩 | UTF-8 (BOM 있음) |
| 업로드 시점 | 【확인 필요】 매일 몇 시경, 전일 데이터인지 당일 누적인지 |
| 원본 보존 | 입력 파일은 수정·삭제하지 않습니다. 재처리는 항상 원본에서 다시 합니다. |

## 2. 채널 파일 컬럼
| 컬럼 | 설명 | 단위 |
|---|---|---|
| 일 | 집계 일자 | YYYY-MM-DD |
| 채널 / 채널분류 | 구글·메타·네이버 / 외부·자체 | - |
| 캠페인 / 캠페인목적 | [네이밍 컨벤션](naming-convention.md) 참고 | - |
| 그룹 / 소재 | 〃 | - |
| 노출, 클릭 | 플랫폼 집계 | 회 |
| **비용** | 광고비 (VAT 포함 여부 【확인 필요】) | 원 |
| 회원가입, 구매 | 플랫폼이 인정한 전환 | 건 |
| 구매매출 | 플랫폼이 인정한 구매 금액 | 원 |

## 3. AppsFlyer 파일 컬럼
일, 미디어소스, 캠페인, 그룹, 소재, 클릭, 회원가입, 구매, 구매매출. **비용·노출이 없습니다.**
ROAS·CPA의 분모(비용)는 항상 채널 파일에서 가져옵니다.

## 4. 미디어소스 → 매체 매핑표
| AF 미디어소스 | 매체 |
|---|---|
| `googleadwords_int` | 구글 |
| `Facebook Ads` | 메타 |
| `naver_search` | 네이버 |

새 미디어소스가 나오면 코드(`pipeline.py`의 `MEDIA_MAP`)와 이 표를 함께 수정합니다. 표에 없는 값은 경고합니다.

## 5. 조인 후 컬럼
- 채널 수치: 노출, 클릭, 비용, 회원가입, 구매, 구매매출
- AF 수치: `AF클릭`, `AF회원가입`, `AF구매`, `AF구매매출`
- `매칭`: `양쪽` / `채널만` / `AF만`

## 6. 알려진 특성
- 채널 대비 AF 비율(2025-01-01): 클릭 91%, 가입 80%, 구매 76%, 매출 83%. 항상 AF가 낮습니다.
- 【확인 필요】 데이터 확정 시점: 플랫폼 전환은 며칠 뒤에 늦게 쌓이는 경우가 있어, 최근 N일 수치가 나중에 바뀔 수 있는지
