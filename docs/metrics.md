# 지표 정의

> 상태: 공식은 구현과 동일하게 확정. `【확인 필요】`는 팀이 정해야 하는 기준입니다.

## 1. 공식
분모가 0이면 결과는 `-`(NaN)이며 0으로 대체하지 않습니다.

| 지표 | 공식 | 구현 컬럼 |
|---|---|---|
| ROAS | 구매매출 ÷ 비용 × 100 | `ROAS`, `AF_ROAS` |
| 구매 CPA | 비용 ÷ 구매 | `CPA`, `AF_CPA` |
| 가입 CPA | 비용 ÷ 회원가입 | `가입CPA`, `AF_가입CPA` |
| CTR | 클릭 ÷ 노출 × 100 | `CTR` |
| CPC | 비용 ÷ 클릭 | `CPC` |
| CVR | 구매 ÷ 클릭 × 100 | `CVR` |
| AF 비율 | AF 수치 ÷ 채널 수치 × 100 | `AF구매비율` 등 |
| 손익분기 ROAS | 1 ÷ 마진율 | `breakeven-roas.html` |

- **합산 지표는 행 평균이 아니라 합계로 다시 계산합니다.** (예: 매체 ROAS = 매체 매출 합계 ÷ 매체 비용 합계)

## 2. 기준 선택
| 질문 | 기본 기준 |
|---|---|
| 매체 간 예산 배분 판단 | **AF 기준** (확정). MMP가 매체 간 같은 잣대라 공정함. 채널 수치는 보조로 병기 |
| 매체 안에서 소재·캠페인 비교 | AF 기준 (예산 판단과 같은 기준 유지) |
| 플랫폼 최적화 상태 확인 | 채널 기준 |

보고서·인사이트에는 **어느 기준인지 항상 명시**합니다. 기준을 섞어 비교하지 않습니다.

## 3. 어트리뷰션
| 항목 | 채널 플랫폼 | AppsFlyer |
|---|---|---|
| 클릭 전환 윈도우 | 【확인 필요】 | 【확인 필요】 |
| 조회 전환 윈도우 | 【확인 필요】 | 【확인 필요】 |
| 중복 제거 | 플랫폼 내부만 | 매체 간 |

AF가 채널보다 낮은 이유(예: 조회 전환 미인정, 윈도우 차이, 매체 간 중복 제거)에 대한 **팀의 공식 설명**을 여기에 적습니다. 이 설명이 없으면 괴리를 해석하지 않고 수치만 보고합니다.
